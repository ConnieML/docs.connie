SMS/Text Channel

Connect with your community through text messaging with ConnieRTC's SMS channel capabilities.

Overview​

The SMS/Text channel enables quick, convenient communication via text messaging. Perfect for notifications, reminders, and brief support interactions that don't require phone calls.

Key Features​

📱 Messaging Capabilities

  • Two-way Texting - Full conversational SMS
  • MMS Support - Images and file sharing
  • Group Messaging - Multi-recipient broadcasts
  • Short Codes - Easy campaign numbers

🤖 Automation Features

  • Auto-Responders - Keyword-triggered replies
  • Appointment Reminders - Automated scheduling
  • Alert Systems - Emergency notifications
  • Opt-in/Opt-out - Built-in compliance

🎯 Use Cases

  • Appointments - Confirmations & reminders
  • Outreach - Events & program updates
  • Support - Quick Q&A and status updates
  • Campaigns - Volunteer & donation drives

⚖️ Compliance & Best Practices

  • TCPA Compliance - Proper consent management
  • 10DLC Registration - Business messaging setup
  • STOP/HELP Keywords - Required opt-out support
  • Quiet Hours - Respect messaging windows

Use Cases​

Appointment Management​

  • Confirmation requests
  • Reminder notifications
  • Rescheduling options
  • Cancellation handling

Outreach & Engagement​

  • Event notifications
  • Program updates
  • Volunteer coordination
  • Donation campaigns

Support Services​

  • Quick questions
  • Status updates
  • Simple troubleshooting
  • Information requests

Provider Integration​

Supported SMS Providers​

  • Twilio - Industry-leading SMS platform
  • Sinch - Global messaging service
  • Bandwidth - Carrier-grade messaging
  • MessageBird - International SMS coverage

Compliance & Best Practices​

Legal Requirements​

  • TCPA Compliance - Proper consent management
  • 10DLC Registration - Required for business messaging
  • Opt-out Handling - STOP, HELP keyword support
  • Message Templates - Pre-approved content formats

Messaging Guidelines​

  • Keep messages under 160 characters
  • Include organization identification
  • Provide opt-out instructions
  • Respect quiet hours (9 AM - 8 PM)

Getting Started​

  1. Choose Provider - Select SMS service provider
  2. Register Campaign - Complete 10DLC registration
  3. Configure Number - Set up dedicated or toll-free number
  4. Create Templates - Build message template library
  5. Test Messaging - Verify send/receive functionality

Advanced Features​

Smart Routing​

  • Keyword-based auto-routing
  • Language detection
  • Priority message handling
  • After-hours responses

Integration Options​

  • CRM synchronization
  • Calendar system connections
  • Email-to-SMS gateway
  • API for custom applications

Analytics & Reporting​

  • Delivery rates
  • Response rates
  • Opt-out metrics
  • Message volume trends
  • Cost analysis

Best Practices​

  • Always get explicit opt-in consent
  • Include clear opt-out instructions
  • Use URL shorteners for links
  • Test messages before bulk sending
  • Monitor delivery reports regularly

Note: SMS channel currently in beta. Contact support for early access.
