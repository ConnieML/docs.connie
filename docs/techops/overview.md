# Connie TechOps

**Internal documentation for Connie staff and technical operations.**

---

This section contains operational documentation used by Connie's internal team to provision accounts, deploy features, and maintain infrastructure. This content is not intended for CBO end users.

## Who Uses These Docs?

- **Connie Engineering** - Platform deployment and feature configuration
- **Connie Support** - Troubleshooting and runbook execution
- **Account Managers** - New client provisioning workflows

## Sections

### Account Provisioning
Step-by-step guides for setting up new client accounts, including Twilio Flex configuration, Auth0 SSO integration, and AWS infrastructure deployment.

### Feature Deployment
Instructions for deploying and configuring ConnieRTC features including voice, voicemail, callbacks, and channel integrations.

### Infrastructure
Reference documentation for AWS resources (S3, CloudFront, Route53), Auth0 tenant management, Twilio account configuration, and Mailgun setup.

### Codebase Reference
Technical documentation covering the ConnieRTC template architecture, frontend/backend structure, and debugging best practices.

### Troubleshooting & Runbooks
Common issue resolution guides, SSO troubleshooting, voice/voicemail diagnostics, and operational runbooks.
