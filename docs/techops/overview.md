# ThreadConnect TechOps

**Internal documentation for ThreadConnect staff and technical operations.**

---

This section contains operational documentation used by ThreadConnect's internal team to provision accounts, deploy features, and maintain infrastructure. This content is not intended for CBO end users.

## Who Uses These Docs?

- **ThreadConnect Engineering** - Platform deployment and feature configuration
- **ThreadConnect Support** - Troubleshooting and runbook execution
- **Account Managers** - New client provisioning workflows

## Sections

### Account Provisioning
Step-by-step guides for setting up new client accounts, including Twilio Flex configuration, Auth0 SSO integration, and AWS infrastructure deployment.

### Feature Deployment
Instructions for deploying and configuring ThreadConnect features including voice, voicemail, callbacks, and channel integrations.

### Infrastructure
Reference documentation for AWS resources (S3, CloudFront, Route53), Auth0 tenant management, Twilio account configuration, and Mailgun setup.

### Codebase Reference
Technical documentation covering the ThreadConnect template architecture, frontend/backend structure, and debugging best practices.

### Troubleshooting & Runbooks
Common issue resolution guides, SSO troubleshooting, voice/voicemail diagnostics, and operational runbooks.
