# Handling Faxes

Faxes in Connie are handled almost identically to emails. If you know how to handle email tasks, you already know how to handle faxes.

## How Faxes Work in Connie

When a fax comes in, it appears in your Task Queue just like any other task. The only differences from email:

- You'll see a **fax icon** instead of an email icon in the Task Queue
- The content is typically a **document image** (PDF or image file) rather than typed text
- Outbound faxes send a document file to a fax number instead of an email address

## Receiving a Fax

1. A new task appears in your **Task Queue** with a fax icon
2. Click the **green checkmark** to accept
3. View the fax content in the **Task Manager** panel — it usually appears as an attached document
4. Open or download the attachment to read the fax

## Sending a Fax

1. Click **"+ New task"** or the compose button
2. Select **Fax** as the channel
3. Enter the recipient's **fax number**
4. Attach the **document** you want to fax
5. Click **"Send"**

## Completing a Fax Task

Same as email:

1. Select a **Disposition** (closing code)
2. Add **notes** about the fax and any actions taken
3. Click **"Complete"**

## Quick Reference

| Action | How to Do It |
|--------|-------------|
| Accept a fax | Green checkmark in Task Queue |
| View fax content | Open attachment in Task Manager |
| Send a fax | + New task → Fax → Enter fax number → Attach document → Send |
| Complete task | Select disposition → Add notes → Complete |
