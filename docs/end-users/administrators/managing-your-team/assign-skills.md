# Assign Skills to an Agent

> **Status:** Drafting. Authoritative content arrives when the internal runbook migration (CON-TBD) surfaces source material. Avoid following this page as a procedure until it is fully published.

Skills control which tasks get routed to which agents. An agent with the "Spanish" skill receives Spanish-language tasks; an agent with the "Intake" skill receives intake-queue work.

## What this page will cover

- Where skills are defined in your Connie instance
- How to add or remove a skill from an existing agent
- Channel capacity (how many simultaneous calls/chats/SMS an agent can handle)
- How skills interact with teams and queues — see [Manage teams & queues](/end-users/administrators/managing-your-team/manage-teams-queues)
- Common skill patterns (language, program, channel-specific)

## In the meantime

To change an agent's skills today, contact your Connie deployment team or open a support ticket with:

1. The agent's Connie email
2. The skill(s) to add or remove
3. Effective date if not immediate
