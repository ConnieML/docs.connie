# Add an Agent

> **Status:** Drafting. Authoritative content arrives when the internal runbook migration (CON-TBD) surfaces source material. Avoid following this page as a procedure until it is fully published.

Adding a new agent to Connie covers: provisioning the user account, assigning a role, configuring channel access, and confirming the new agent's display name renders correctly across internal and external surfaces.

## What this page will cover

- Prerequisites (admin role, available seat, agent's email address)
- Account creation flow in the admin panel
- Role assignment (Staff Agent / Supervisor / Admin) — see [Roles & permissions](/getting-started/roles-permissions)
- First-login walkthrough for the new agent
- Confirming display name is correct (see [Display names](/end-users/administrators/managing-your-team/display-names))

## In the meantime

To add a new agent today, contact your Connie deployment team or open a support ticket with:

1. The agent's full First Last name
2. Their email address
3. The role they should have (Staff Agent, Supervisor, or Admin)
4. Which channels they need access to (voice, SMS, webchat, email, etc.)
