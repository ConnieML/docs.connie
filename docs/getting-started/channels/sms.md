# SMS/Text Channel

Connect with your community through text messaging with ConnieRTC's SMS channel capabilities.

## Overview

The SMS/Text channel enables quick, convenient communication via text messaging. Perfect for notifications, reminders, and brief support interactions that don't require phone calls.

## Provider Integration

### Supported SMS Providers
- **Twilio** - Industry-leading SMS platform
- **Sinch** - Global messaging service
- **Bandwidth** - Carrier-grade messaging
- **MessageBird** - International SMS coverage

## Compliance & Best Practices

### Legal Requirements
- **TCPA Compliance** - Proper consent management
- **10DLC Registration** - Required for business messaging
- **Opt-out Handling** - STOP, HELP keyword support
- **Message Templates** - Pre-approved content formats

### Messaging Guidelines
- Keep messages under 160 characters
- Include organization identification
- Provide opt-out instructions
- Respect quiet hours (9 AM - 8 PM)

## Getting Started

1. **Choose Provider** - Select SMS service provider
2. **Register Campaign** - Complete 10DLC registration
3. **Configure Number** - Set up dedicated or toll-free number
4. **Create Templates** - Build message template library
5. **Test Messaging** - Verify send/receive functionality
