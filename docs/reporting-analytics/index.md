# Reporting & Analytics

Connie reporting comes in two tiers.

## 🟦 Basic

*Included with every Connie account.*

- **Real-time** — live activity in Teams View
- **Historical** — reporting by channel type

→ **"What happened."** Out-of-the-box, nothing to set up.

## 🟪 Advanced

*Paid upgrade.*

- The same Basic data, plus **powerful time-saving filters & views**
- **State / funder / board-ready** reporting

→ **"Same data, already in the shape your funders want."**

:::note This is evolving
Reporting & Analytics is actively developing — these docs capture the essentials today and will grow over time.
:::

Terms used across these guides are defined in the **[Concepts & Glossary](/reporting-analytics/concepts-glossary)**.
