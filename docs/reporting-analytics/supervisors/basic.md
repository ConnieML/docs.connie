# Basic Reporting

> 📦 **Basic — included with every Connie account.**

In **Basic**, supervisors and administrators have the **same reporting** — the same dashboards, Analyze, exports, and time frames. So it's documented in one place to keep things simple.

➡️ **[Open the full Basic Reporting guide →](/reporting-analytics/administrators/basic)**

It covers: where to find reporting, who has access, customizing dashboards, switching time frames, how far back the data goes, exporting, and a plain-language glossary.
